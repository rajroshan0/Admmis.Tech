# Microcopy

Format: `key: text`. Sections are added as pages need them. Keys map to message keys under `common.*`.

## common (accessibility and navigation)
- common.skipToContent: Skip to main content
- common.menuOpen: Open menu
- common.menuClose: Close menu
- common.menuLabel: Main menu
- common.languageSwitch: Language
- common.backToTop: Back to top
- common.readMore: Read more
- common.opensInNewTab: (opens in a new tab)

## faq
- faq.expand: Show answer
- faq.collapse: Hide answer

## sticky bar (aria labels)
- stickyBar.whatsappAria: Chat with us on WhatsApp
- stickyBar.callAria: Call ADMMIS.TECH
- stickyBar.quoteAria: Get a quote
