# design/logo: which files are final

Owner: sharwan. Updated 2026-11-07 (T-601, redirected by PM).

**Source:** Roshan's own logo `design/inputs/admmis.tech logo.png` (1254 x 1254), vectorised as SVG. This is a **redraw of a PNG, not an original vector**: geometry measured from the pixels, hexagon, "A", swoosh and circuit lines rebuilt as clean paths, wordmark and ring text converted from Montserrat ExtraBold and Space Mono Bold outlines (visual match, not the original letterforms).
